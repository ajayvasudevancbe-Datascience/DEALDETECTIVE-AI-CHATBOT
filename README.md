# 🕵️ DealDetective AI

**Find the deal. Check the value. Buy smarter.**

DealDetective AI is a **GenAI-powered shopping intelligence chatbot** built with Python and Streamlit. It helps users analyze products, investigate discounts, understand reviews, compare options, and make smarter buying decisions.

- Should I buy now or wait?
- Find a better alternative within my budget.

## 🎯 Project Goal

Online shopping provides thousands of products, discounts, ratings, and reviews. However, finding the **actual value of a deal** can be difficult.

DealDetective AI works as a **digital shopping investigator** that analyzes available product information and provides a simple buying decision:

**🟢 BUY | 🟡 WAIT | 🔴 AVOID | 🔄 ALTERNATIVE**
